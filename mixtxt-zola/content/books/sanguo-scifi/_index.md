# 简介

星历一百八十四年，东汉星域。

汉室统御这片银河已历两百年，皇权旁落，星区割据。灵渠干涸，星图蒙尘，一艘艘光甲战舰在旧帝国的边境线上锈蚀朽烂——人人都说，汉家的气数尽了。而在涿郡星一处偏远的市集上，织席贩履的少年刘备，还只想着今日的草席能不能多卖出一张。

他是中山靖王之后，一纸族谱早被战火烧去大半，只剩一个"刘"字，压着他活下去。

世道将乱，乱在巨鹿。张角得《太平要术》残卷，以脑控符箓惑乱亿万黔首，一声令下，黄巾如蝗，自大河星域一路烧向帝都。天下闻风丧胆之际，一个没落宗室、两个粗豪武人，在桃园里盟了誓，铸了刀，驾着旧到掉漆的农用光甲，一头扎进这场改朝换代的大乱。

这是三国，也不是三国。这里是脑控光甲的时代——人以精神契合机械，师士以脑波御甲，强者一念可碎星，弱者一世耕田。边境那座以"龙城"为名的机甲重镇，收留天下无家可归的师士，也藏着汉室最深的秘密：传说中失落了百年的帝王光甲"龙城"，就沉睡在某处，等一个认得出它的人。

刘备起初只想活，后来想立，再后来，想这天下。

他不靠血脉，不靠贵人，只靠一双会调甲的手，和三个肯把命托付给他的兄弟。从涿郡市集到龙城学府，从黄巾乱军到诸侯会盟，从赤壁火海到蜀道天堑——他要在这盘乱世的大棋里，一步步把"刘"字，走成天下人心里的那个字。

龙城未醒，英雄未老。

这一路，刀光与机甲同鸣，权谋共星火齐燃。织席贩履的少年，终要问鼎星海。
