# 简介

自齐天大圣压于五行山下、唐僧一行取经功成，悠悠已是数百载。

佛门香火绵延，天庭威仪未减，可凡尘早已悄换了光景——灵气一年薄过一年，仙箓久不向凡间开，山野修士难再白日飞升。长生一道，成了世家名门把持的独木桥；桥对面，是挤不进去的泥腿子。

青牛村采药少年陆尘，便生在这样一座灵气将枯的小村。他不信仙佛，只信手里的药篓、灶上的汤药。爹早亡，娘病在炕，三间茅屋，压在他一个未及弱冠的娃肩上。直到那日采药遇险，误入山腹古洞，从一具枯坐不化的无名骸骨手中，取下一枚青玉小瓶。

瓶能逆转草木枯荣。一夜之间，枯枝抽芽，凡种成灵；连胸口那股压了十四年的闷，也像被谁轻轻揉开。一瓶在手，命数拐弯。可他不做衣锦还乡的齐天大圣，也不求超脱物外的斗战胜佛——他只想借着这桩机缘，从炼气、筑基、结丹一步步走上去，护住病弱的娘，挣一条凡人的长生路。

只是这世间，仙佛未远，妖魔未绝。五行山下旧猿的封印时时松动，西行路上的旧劫卷土重来，天庭与灵山为续香火，又要寻一班新的取经人。一个只想活命的凡人，被这盘三界大棋轻轻一拨，便成了谁都料不到的闲子。而那青玉小瓶，原也不过是个引子——缠着它那枚刻着"乾坤崩于一旦、勿授非人"的残旧布帛，早在陆尘降生之前，就指向一盘落定许久的残局。

他没有补天的宏愿，也没有成圣的执念。只趁西行旧劫重演，借一路惊险，换母子俩一线活路；借一场凡圣之争，挣出凡人的长生。待天地安定那日，他要把引气、守气、行气的法子，一条条，也教给天底下和他一样的泥腿子——让那扇从不向凡人开的仙门，从此留一线的缝。

大道无名。采药郎要活着，立着，回到青牛村。
