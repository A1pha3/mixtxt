# 简介

天地玄黄，宇宙洪荒。自齐天大圣压于五行山下、唐僧西行取经功成，已是悠悠数百载。

佛门香火绵延，天庭威仪未减，可三界的凡尘，却悄悄换了光景——灵气一年薄过一年，仙箓久不向凡间开启。山野修士，再难像古时那般白日飞升；长生一道，成了世家大族与名门正派把持的独木桥。

青牛村采药少年陆尘，便生在这样一座灵气将枯的凡间小村。他不信仙佛，只信手里的药篓和灶上的汤药。直到那日避祸误入山腹古洞，从一具无名枯骨手中，取下一枚青玉小瓶——瓶能逆转草木枯荣，一夜之间，令枯枝抽芽、凡种成灵。

一瓶在手，陆尘的命数就此拐了弯。他不做那呼风唤雨的齐天大圣，也不求那超脱物外的斗战胜佛；他只想借着这桩机缘，一步步从炼气、筑基、结丹走上去，护住病弱的娘，活一条自己的长生路。

可这世间，仙佛未远，妖魔未绝。五行山下旧猿的封印时有松动，西行路上的旧劫卷土重来，天庭与灵山为续香火，又要寻一班新的取经人。一个只想活命的凡人，被这盘三界大棋轻轻一拨，竟成了谁都料不到的那枚闲子。他这才慢慢看明白：青玉瓶不过是个引子——这桩机缘的背后，藏着一盘早在他降生之前便已落好的残局。

陆尘没有补天的宏愿，也没有成圣的执念。他只想趁西行旧劫重演，借一地惊险换母子俩的活路，借一场凡圣之争挣出自己的长生；待天地镇定，再把引气、守气、行气的法子，一条一条，教给天底下和他一样的泥腿子。仙箓真开，不在那末班三百，在凡间人人可得的一线气；大道无名，归去来兮，采药郎要立着回到青牛村。

本书以《西游记》之神魔气象为骨架，以《凡人修仙传》之务实修炼为血脉，写尽凡人在仙佛夹缝中，一步一步、偷天换日的修行路。
