# 简介

天地玄黄，宇宙洪荒。自齐天大圣压于五行山下、唐僧西行取经功成，已是悠悠数百载。

佛门香火绵延，天庭威仪未减，可三界之下，凡尘却悄悄换了光景——灵气一年薄过一年，仙箓久不向凡间开启。山野之间的修士，再难如古时那般白日飞升；长生一道，成了世家大族与名门正派把持的独木桥。

青牛村采药少年陆尘，便生在这样一座灵气将枯的凡间小村。他不信仙佛，只信手里的药篓和灶上的汤药。直到那日避祸钻进山腹古洞，从一具无名枯骨手中取下一枚青玉小瓶——瓶能逆转草木枯荣、催熟灵植，乃是当年地仙之祖镇元子一脉"时空道则"的残片，随一场上古崩乱散落凡尘。

一瓶在手，陆尘的命数就此拐了弯。他不愿做那呼风唤雨的齐天大圣，也不想成那超脱物外的斗战胜佛；他只想凭着这桩机缘，一步步从炼气、筑基、结丹走上去，护住病弱的娘，活一条属于自己的长生路。

可这世间，仙佛未远，妖魔未绝。五行山下旧猿的封印时有松动，西行路上的旧劫换了新皮囊卷土重来，天庭与灵山为续香火，又要寻一班新的取经人。一个只想活命的凡人，被这盘三界大棋轻轻一拨，竟成了谁都料不到的那枚闲子。

本书以《西游记》之神魔气象为骨架，以《凡人修仙传》之务实修炼为血脉，写尽凡人在仙佛夹缝中，一步一步、偷天换日的修行路。

一瓶、一镜、一猿、一鬼，同源四片，自枯骨手中授于活人，由凡身主导聚而补天——仙箓真开，不在三百末班，在凡间人人可引的一线气；大道无名，而归去来兮，采药郎立着回了青牛村。

然新天初立未稳，天穹犹余一缝，北冥古钟自鸣——九钟九钥，八处待补，蚀祖尚眠。采药郎的第二程，才刚启程。
