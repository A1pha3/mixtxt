# 2026-08-01 工作日志

## docs/product 文档整合重构

**任务**：docs/product 下有 10 份文档（约 9000 行）存在大量重复内容，按第一性原理整合为少量文档，方便查看。

**发现**：所有文档实际服务于两个完全不同的项目场景——
- 场景 A：AI 改编小说网（单作者、Markdown 正本、无数据库、只读、Git 版本管理）→ 静态站方案
- 场景 B：小说内容付费平台（多本书、付费/VIP、订单、用户、后台、AI 生成）→ 动态方案

重复点：章节权限规则、支付幂等流程、数据模型（users/books/chapters/purchases/vip）、AI 工作流、Cloudflare 免费层限制、版权边界、版本管理三层模型等在 5-6 份文档中反复出现。

**产出**（docs/product/ 顶层仅 4 个文件）：
- `README.md` — 导航索引 + 全局设计约定
- `01-需求与方案选型.md` — 场景区分、7 类方案对比、最终推荐、演进路线（入口文档）
- `02-动态付费平台架构设计.md` — 共享核心设计（数据模型/权限/支付/AI/安全）+ Payload CMS 3 / Next.js+Supabase（含完整 SQL/RLS/支付代码）/ 微信小程序（含从零初始化教程）/ PocketBase 四方案
- `03-轻量静态站架构设计.md` — 共享基础（内容模型/章节导航/版本管理/部署限制/版权）+ 推荐方案 Astro+Pages CMS 完整设计 + Hugo / Astro+Keystatic 备选

**归档**：原 10 份文档移入 `docs/product/archive/`（保留备查，未删除）。

**效果**：8987 行 → 2002 行（减少约 78%），无乱码，代码块全部闭合。
