## 对抗性审查第 3 轮：Zola 方案（doc 04 v1.0 → v1.1）

**核实（多源，2026-08-17/18）**：
- **Zola 内置 Elasticlunr 对中文分词不可用**（官方文档要求非英语额外引入 stemmer；elasticlunr.js 2017 停更；多位中文博主实测失败）→ 中文站搜索唯一可靠方案是 Pagefind（v1.5+ 原生 CJK 分词、构建后扫描 public/）。
- Zola 最新稳定版 **0.23.3**（2026-08-12，修复低危安全漏洞）；Cloudflare Pages v2 默认 0.22.1 仍有效。
- section `render=false` 只关 section 自身页面，**不阻止子页面渲染**（官方 discourse 确认；render=false 页面仍进 taxonomy）。
- Zola 官方：**date 不要用引号包 RFC3339**；page 级也有 render/hidden 字段；section `draft=true` 使其子孙一律不处理。
- `zola check` **默认检查外部链接**（发 HTTP 请求），`--skip-external-links` 可跳过。
- Pagefind v1.5.0（2026）automatic CJK segmentation、Web Worker、分块索引。

**修复（doc 04 + 联动 01/03，共 15+ 处）**：
1. **搜索重写 §2.9**：Elasticlunr 主推 → Pagefind 主推（构建后 `npx pagefind --site public`）；手写 JS API 版搜索页（textContent 防 XSS）；`build_search_index=false`；`data-pagefind-body` 从"预留"转正。
2. **hidden 书 = section `draft=true`**（映射表 + §2.6 书示例 + validate 强制联动）——修掉"hidden 书页面仍被构建公开访问"的真实漏洞。
3. **prompts 移出 `content/`** → 仓库根 `prompts/`（render=false 语义脆弱，零歧义隔离）。
4. **删 `[extra.seo]` 死数据**（模板从未读取，且改 title 忘改 seo.title 会漂移）。
5. **validate_content.py 重写**：修注释与实现不符 + 死代码 slug_re；新增文件名/weight/chapterNo 三者一致门禁、date 格式校验、hidden→section draft 联动；frontmatter 解析改正则（旧 find 写法遇含 "+++" 的字符串会误截断——已测）。
6. **harness fail-fast**：生成前读 `_index.md` 检查 copyrightStatus ∈ {public-domain, authorized}，不满足不调 LLM、不写文件；date 输出改无引号 TOML datetime。
7. **ZOLA_VERSION 0.23.2 → 0.23.3**；build 命令/CI 加 pagefind 步骤；404.html、minify_html、taxonomy 说明补齐；§2.16 风险表 +4 行；doc 01/03 的 Zola 描述同步修正"内置搜索"表述。

**闭环验证**：三文档代码块闭合（8/42/46）、无乱码；提取两脚本 py_compile 通过；10 个行为用例全过（合法内容/三者不一致/非法文件名/hidden 门禁/日期非法/版权门禁/fail-fast/dry-run 无引号日期/未闭合 frontmatter/含+++字符串不误截断）。

**关键新结论**：Zola 的"内置搜索"卖点对中文站不成立，需 Pagefind（唯一外部依赖，Cloudflare 环境自带 Node）；hidden 语义在 Zola 的正确实现是 section draft 而非模板过滤。

## 对抗性审查第 4 轮：Zola 方案（doc 04 v1.1 → v1.2）

4. **Pagefind 固定 @1.5.2**（CF build / Actions / build.sh / §2.2 四处统一）+ extended 版说明 + Python 免 Node 跑法。
5. validate 加 **extra.book 与目录一致** 校验（此前注释称"冗余校验用"但从未实现）。
6. harness：缺 `LLM_API_KEY` 友好报错（原 KeyError traceback）；429/5xx 退避重试 3 次；`--title` 缺省读 `_index.md` 真实书名（原用 slug）；desc 去首行 Markdown 标题标记。

**闭环验证**：48 围栏闭合、无乱码；两脚本 py_compile 通过；行为用例：book 不一致被拦/一致通过/缺 Key 友好退出/dry-run 无引号日期无 in_search_index；残留扫描 0。

**经验**：① `data-pagefind-body` 内的导航等噪音必须 `data-pagefind-ignore`；② 直接下载 Pagefind 二进制做中文站必须选 extended 版；③ 每轮审查要回头扫上一轮改动是否引入新的误导注释/残留旧表述。
