# 《星汉三国》原创科幻设定手册（去侵权重构基准）

> 本手册为逐章重构的"宪法"。所有重构章节须以本手册的设定内核为准，彻底脱离方想《龙城》的"师士/光甲/认己/满城/七片归一"体系。
> 原则：与《龙城》在**力量逻辑、主题内核、命名**三个维度全部正交。

## 0. 去侵权边界（硬性）

- ❌ 禁止概念：脑控光甲、师士、龙城、以己认甲、七片归一、满城之桥、认肯不认收、肯沉归城、问手台、沉心井、玄械城之心"认人"、收而不予。
- ❌ 禁止立意：个体之"己"与"满城"（集体）之间能否走通桥梁——此即《龙城》核心主题，必须替换。
- ✅ 本作可用底本：罗贯中《三国演义》（公有领域），人物与史实框架可沿用；科幻外壳须为本文档原创。

## 1. 世界观内核（原创）

**星汉之契**：上古"汉"文明在银河播下一张星图契约网络，以"契文"统御各星区。契文不是能量，是**文明存续的约定**——农者耕星、工者铸械、医者续命、战者守疆、史者记真、律者定序、匠者通联，七职各守其契，星海方稳。

**断契之世**：汉室统御两百年后，星契崩解（灵渠=星契主脉干涸），七职失序，星区割据。各方争夺的不是"认城之心"，而是**「契核」**——能重写/修复星契的远古枢纽，藏于星枢之城"璇枢"深处。

**主题轴心（替换《龙城》的认归主题）**：**文明火种的信约与代际传递**——一个没落宗室后裔如何重新接续断掉的文明契约，让散落的七职重新咬合。冲突的胜负手是"能否续契、能否履约"，而非"能否认己/归城"。

## 2. 力量与机甲体系（原创，替换光甲/师士）

- **契文（Qiwen）**：星图契约的具象化符纹，每个人/族群与生俱来一道"本契"（对应七职之一）。
- **机甲 = 契文的具象载体**：启动机甲靠**「解契」**——理解并履行自己本契所对应的职责，而非"以肯焐人认甲"。解契越深，机甲越强。
- **调契师**：能读取、修复他人契文的匠人（替换"调甲师/师士"）。刘备的天赋是"解契手巧"——凡经手的契文机件，他看一遍就能理顺其纹路。
- **契核（Qiehe）**：璇枢城深处的远古枢纽，重写星契的总闸。传说失落百年，等一个"能解七契之人"。

## 4. 主要人物线（在三国骨架上重挂原创内核）

- **刘备**：中山靖王支系没落后裔，本契未显，却天生"解契手巧"。从不靠血脉，靠一手理顺契文的手，与两弟（关张）及后来诸葛，重续断掉的星汉之契。核心弧光：**从"无契之人"到"能解七契之人"**。
- **曹操**：本契为"律"（定序），却想独占契核、以一己之律重写星契（断契独握），与刘备"续契共契"对立。
- **孙权/周瑜**：江东"工""战"双契世家，守自家族契，观望星契归属。
- **诸葛亮**：本契为"史"（记真），携完整星契图谱出山，是"解契"的导师型人物。

3. 顶部创作提纲注释（HTML 注释）同步重构，删除"七片归一/满城之桥"等旧内核描述。
4. 不改三国史实骨架与人物关系（公版），只改科幻设定层。
