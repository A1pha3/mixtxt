# AI改编小说网需求

- 改编小说网是一个基于AI技术的改编小说平台，是利用AI技术改编一些著名小说的平台。
- 我希望这个网站功能比较简单，只是用来保存用户改编的小说，因为这些小说都是用户通过AI技术创作的，不需要任何的审核。并且要有版本管理功能，用户可以查看自己创作的小说的所有版本。
- 我希望这个网站用户可以很容易地使用，小说用markdown格式保存，不需要数据库，只是文本文件形式保存。只有我一个创建者，其他用户只能查看不能编辑。
- 因此，我需要一个简单的用户界面，用户可以很容易地查看和管理自己的创作。并且能把用户创作的小说的所有章节关联起来，用户可以在界面上查看和管理。
- 我希望这个网站的性能比较快，用户可以很快地查看和管理自己创作的小说。

- 我觉得用hugo框架来实现这个网站，因为hugo是一个静态网站生成器，可以快速地生成网站，不需要数据库。
- 你觉得合理吗？你还有更好的方案吗？把你的答案整理成一个文档，名为:AI改编小说网架构.md, 保存在 docs/product/ 目录下。
