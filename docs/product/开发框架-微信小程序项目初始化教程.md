# 小说付费阅读微信小程序项目初始化教程

> 文档类型：项目初始化教程
>
> 适用人群：**微信生态零基础 / 小程序新手 / 个人开发者**
>
> 教程目标：从 0 开始完成一个可运行的小说阅读小程序雏形，打通下面这些环节：
>
> - 注册并配置微信小程序
> - 安装微信开发者工具
> - 创建小程序项目
> - 开通并配置云开发
> - 建立书籍和章节数据集合
> - 导入示例数据
> - 跑通首页、书籍详情页、章节阅读页
>
> 配套文档：

> - [开发框架方案对比与推荐.md](./开发框架方案对比与推荐.md)

## 学习目标

完成这篇教程后，你应该能做到：

1. 看懂微信小程序开发的最基本工作流
2. 自己创建一个可以运行的小说阅读小程序项目
3. 在微信云开发中建立最小可用的数据结构
4. 让小程序从云数据库读出书籍列表、书籍详情和章节内容
5. 理解下一步该如何继续做登录、支付、VIP 和后台

这篇教程只解决“**先跑起来**”的问题，不在第一步就引入支付、复杂权限、AI 生成和审核流程。先把最小阅读闭环跑通，后续扩展才不会乱。

---

## 一、先明确这篇教程能帮你做成什么

做完本教程后，你会得到一个最小可运行版本：

### 已完成的能力

- 小程序项目能在开发者工具中运行
- 首页可以显示书籍列表
- 点击书籍可以进入详情页
- 详情页能展示章节列表
- 点击章节可以进入阅读页
- 正文内容来自云数据库，不是写死在页面里

### 还没有做的能力

- 微信登录
- 付费章节拦截
- VIP 开通
- 微信支付
- 书架
- 阅读进度
- 后台管理

这是故意的。新手最容易犯的错误，是在第一个阶段就把系统目标定得过大，结果卡在一堆前置问题里。正确顺序是：

> 先把“内容能展示”跑通，再做“用户是谁”，最后再做“谁能付费看”。

## 二、开始前需要准备什么

### 2.1 必备账号

至少准备下面这些：

1. **微信公众平台小程序账号**
2. **微信开发者工具**
3. **一个微信号**（用于扫码登录开发者工具）

### 2.2 推荐本地工具

建议电脑上提前装好：

- **微信开发者工具**
- **VS Code**
- **Git**
- **Node.js**（这篇教程暂时不强依赖，但后面做脚本时会用到）

### 2.3 先不要准备的东西

现阶段你还不需要：

- 微信支付商户号
- 正式域名
- 服务器
- 自建数据库
- 复杂管理后台

这些都不是“跑起第一个版本”的前置条件。

## 三、注册并创建微信小程序

### 3.1 注册入口

进入微信公众平台，注册一个 **小程序**。

如果你已经有账号，可以直接登录；如果没有，就按平台流程完成注册。

### 3.2 创建完成后，你需要记住什么

创建成功后，重点关注下面两个信息：

- **AppID**
- **小程序管理员权限**

后面在微信开发者工具里创建项目时会用到 `AppID`。

### 3.3 新手提醒

如果你现在只是想先学开发、先把项目跑起来，也可以临时使用“测试号 / 无 AppID 调试模式”一类方式先练手，但真正要走云开发和后续上线，最终还是要回到正式小程序项目。

所以更推荐一开始就用自己的小程序账号来做。

## 四、安装并配置微信开发者工具

### 4.1 安装

安装完成后，打开微信开发者工具，用你的微信扫码登录。

### 4.2 第一次打开后要做的事

建议先确认：

- 能正常登录
- 能看到“小程序”开发入口
- 本地项目目录可正常选择

### 4.3 为什么开发者工具很重要

它不只是一个编辑器，更像是：

- 编译器
- 运行器
- 模拟器
- 上传工具
- 体验版发布工具

你后续的大多数小程序开发动作，都会在这里完成。

---

## 五、创建第一个项目

### 5.1 新建项目

在微信开发者工具中点击“新建小程序项目”，填写：

- **项目目录**：例如 `~/projects/miniprogram-novel`
- **AppID**：填写你的小程序 AppID
- **后端服务**：选择“微信云开发”
- **语言**：建议使用 JavaScript 先跑通，再考虑 TypeScript

### 5.2 为什么推荐先选云开发

因为这能让你在最短路径内得到：

- 数据库
- 云函数
- 文件存储

对于新手来说，这比先接自建后端轻得多。

### 5.3 项目创建后，你会看到什么

通常会有一个初始目录结构，大致类似：

```text
miniprogram-novel/
├── miniprogram/
├── cloudfunctions/
├── project.config.json
└── project.private.config.json
```

其中：

- `miniprogram/`：小程序前端代码
- `cloudfunctions/`：云函数
- `project.config.json`：项目配置

## 六、认识小程序项目结构

### 6.1 先看最关键的 4 类文件

在 `miniprogram/` 目录里，你会经常碰到这几类文件：

- `.wxml`：页面结构
- `.wxss`：页面样式
- `.js`：页面逻辑
- `.json`：页面配置

### 6.2 小程序和普通 Web 项目的区别

如果你之前写过 Web，最容易混淆的一点是：

- 小程序不是浏览器网页
- 它有自己的组件系统、生命周期和 API
- 页面跳转、数据更新、事件绑定都有自己的写法

这并不意味着很难，只是你需要接受：

> 小程序是一套独立平台，不是把 HTML/CSS/JS 原样搬过去。

### 6.3 现在先不要追求“框架化”

很多人一上来就想问：

- 要不要上 Taro？
- 要不要上 TypeScript？
- 要不要上状态管理？

现在都先不用。第一步的目标只有一个：

> **把书籍列表从云数据库读出来并显示在页面上。**

## 七、开通云开发环境

### 7.1 什么是云开发环境

可以把它理解为你当前这个小程序项目的“后端空间”。

里面通常包括：

- 云数据库
- 云函数
- 云存储

### 7.2 创建云开发环境

在微信开发者工具中找到云开发入口，创建一个新环境。

建议环境命名方式：

- `novel-dev`：开发环境
- `novel-test`：测试环境（后续可选）
- `novel-prod`：生产环境（上线前再建）

如果你现在是第一次做，只创建一个开发环境也可以。

### 7.3 为什么建议从一开始就区分环境

因为将来你会发现：

- 开发中的测试数据不能总和正式数据混在一起
- 支付测试、体验版测试、真实用户数据需要分隔

不过首发阶段为了简单，一个开发环境足够。

---

## 八、初始化云开发能力

### 8.1 在 `app.js` 中初始化

打开 `miniprogram/app.js`，写入最小初始化逻辑：

```javascript
App({
  onLaunch() {
    if (!wx.cloud) {
      console.error('请使用支持云开发的基础库')
      return
    }

    wx.cloud.init({
      env: 'novel-dev',
      traceUser: true,
    })
  },
})
```

### 8.2 这里每个字段是什么意思

- `env`：你的云开发环境 ID
- `traceUser: true`：让云开发更容易识别当前用户上下文

### 8.3 你需要把什么替换掉

把 `novel-dev` 换成你自己实际创建的云开发环境 ID。

如果你不确定环境 ID，可以在开发者工具的云开发面板里查看。

## 九、创建数据库集合

现在开始建立最小数据结构。先别建太多集合，只建这两个：

- `books`
- `chapters`

### 9.1 为什么先只建两个集合

因为我们现在只想跑通：

- 首页书籍列表
- 书籍详情页
- 章节阅读页

这三个页面只依赖内容数据，不依赖用户、订单、VIP。

### 9.2 创建 `books`

在云数据库中创建集合：`books`

建议字段结构如下：

```json
{
  "bookId": "book-001",
  "title": "示例小说",
  "authorName": "作者A",
  "coverUrl": "https://example.com/cover.jpg",
  "description": "这是一本用于演示的小程序小说。",
  "status": "serializing",
  "isPublished": true,
  "chapterCount": 2,
  "sortOrder": 1,
  "createdAt": "2026-04-28T10:00:00.000Z"
}
```

### 9.3 创建 `chapters`

再创建集合：`chapters`

建议字段结构如下：

```json
{
  "chapterId": "chapter-001",
  "bookId": "book-001",
  "title": "第一章 初到异界",
  "chapterOrder": 1,
  "content": "这是第一章正文内容。",
  "isVIP": false,
  "status": "published",
  "createdAt": "2026-04-28T10:00:00.000Z"
}
```

### 9.4 字段先保持克制

现在不要一开始就加：

- 价格
- 订单状态
- AI 模型信息
- 评论统计
- 阅读统计

因为这些不会帮助你更快跑通第一个版本。

### 11.2 配置首页路由

在 `app.json` 中配置页面顺序：

```json
{
  "pages": [
    "pages/home/home",
    "pages/book-detail/book-detail",
    "pages/chapter-reader/chapter-reader"
  ],
  "window": {
    "navigationBarTitleText": "小说阅读",
    "navigationBarBackgroundColor": "#ffffff",
    "navigationBarTextStyle": "black"
  }
}
```

### 11.3 首页逻辑代码

`pages/home/home.js`：

```javascript
const db = wx.cloud.database()

Page({
  data: {
    books: [],
    loading: true,
  },

  onLoad() {
    this.loadBooks()
  },

  async loadBooks() {
    try {
      const res = await db.collection('books')
        .where({ isPublished: true })
        .orderBy('sortOrder', 'asc')
        .get()

      this.setData({
        books: res.data,
        loading: false,
      })
    } catch (error) {
      console.error('加载书籍失败', error)
      this.setData({ loading: false })
    }
  },

  goToBookDetail(e) {
    const { bookid } = e.currentTarget.dataset
    wx.navigateTo({
      url: `/pages/book-detail/book-detail?bookId=${bookid}`,
    })
  },
})
```

### 11.4 首页模板代码

`pages/home/home.wxml`：

## 十二、创建书籍详情页

### 12.1 新建页面目录

```json

}
```

### 12.2 页面逻辑

`pages/book-detail/book-detail.js`：

```javascript
const db = wx.cloud.database()

Page({
  data: {
    book: null,
    chapters: [],
  },

  async onLoad(options) {
    const { bookId } = options
    await Promise.all([
      this.loadBook(bookId),
      this.loadChapters(bookId),
    ])
  },

  async loadBook(bookId) {
    const res = await db.collection('books')
      .where({ bookId })
      .get()

    this.setData({
      book: res.data[0] || null,
    })
  },

  async loadChapters(bookId) {
    const res = await db.collection('chapters')
      .where({
        bookId,
        status: 'published',
      })
      .orderBy('chapterOrder', 'asc')
      .get()

    this.setData({
      chapters: res.data,
    })
  },

  goToChapter(e) {
    const { chapterid } = e.currentTarget.dataset
    wx.navigateTo({
      url: `/pages/chapter-reader/chapter-reader?chapterId=${chapterid}`,
    })
  },
})
```

### 12.3 页面模板

`pages/book-detail/book-detail.wxml`：

```xml
<view class="page" wx:if="{{book}}">
  <image class="cover" src="{{book.coverUrl}}" mode="aspectFill" />
  <view class="title">{{book.title}}</view>
  <view class="author">{{book.authorName}}</view>
  <view class="desc">{{book.description}}</view>

  <view class="section-title">章节列表</view>

  <view wx:for="{{chapters}}" wx:key="chapterId" class="chapter-item" data-chapterid="{{item.chapterId}}" bindtap="goToChapter">
```

- 数据是否能按 ID 取到
- 阅读页是否能正确渲染正文

付费判断应该放在下一个阶段做，否则你会同时调试太多东西。

---

## 十四、现在进行第一次完整自测

请按下面顺序操作一次：

1. 打开首页
2. 看是否出现书籍卡片
3. 点击书籍进入详情页
4. 看是否出现章节列表
5. 点击章节进入阅读页
6. 看是否出现正文

如果这 6 步都通了，你已经完成了一个最小可运行的小程序阅读项目。

## 十五、出现问题时先查哪里

### 15.1 首页空白

优先检查：

- `wx.cloud.init` 的环境 ID 是否正确
- `books` 集合里是否有数据
- `isPublished` 是否为 `true`
- 控制台是否有云开发报错

### 15.2 详情页没有章节

优先检查：

- `chapters.bookId` 是否和 `books.bookId` 完全一致
- `status` 是否是 `published`
- `chapterOrder` 字段是否存在

### 15.3 阅读页没有正文

优先检查：

- `chapterId` 路由参数是否传对
- `chapters` 集合中的 `chapterId` 是否正确
- `content` 字段是否有值

### 15.4 页面跳转报错

优先检查：

- `app.json` 里是否声明了对应页面
- 页面路径和目录名是否完全一致

### 15.5 云数据库查询返回不完整

如果你发现数据超过 20 条但只显示了 20 条，这是云数据库的默认限制：

- `get()` 单次最多返回 20 条记录
- 超过 20 条需要使用 `skip` 和 `limit` 手动分页
- 或使用云函数中转查询（云函数中可突破 20 条限制，最多一次返回 100 条）

### 15.6 安全提示

当前教程直接从客户端读取云数据库，适合学习和原型验证。正式上线前需要：

- 在云开发控制台为每个集合配置**安全规则**（如 books/chapters 仅允许读取，orders 仅允许写）
- 付费章节的正文不应直接暴露在客户端查询中，应在后续阶段改用云函数控制返回内容

## 十六、这一阶段为什么不写云函数

你可能会问：既然都用了云开发，为什么不一开始就写云函数？

原因是当前这一步不需要。

现在的数据读取逻辑很简单：

- 查书籍
- 查章节
- 查单章内容

直接从云数据库读取就够了。

等你进入下一阶段，再引入云函数处理这些更适合服务端的事情：

- 微信登录补全
- 付费权限判断
- 创建订单
- 支付回调
- 阅读进度保存

这是更稳的学习路径。

---

## 十七、下一步你该做什么

完成本教程后，最自然的下一步不是“立刻上线”，而是做下面 3 件事。

### 17.1 第一步：加微信登录

目的：识别谁在看书。

没有登录，你无法做：

- 购买记录
- 书架
- 阅读进度
- VIP

### 17.2 第二步：给章节加权限层

目的：区分免费章节和付费章节。

建议做法：

- 先给 `chapters` 集合里的 `isVIP` 字段赋值
- 阅读页访问时先判断权限
- 无权限时显示付费墙，而不是正文

### 17.3 第三步：接入支付

目的：让用户能真正开通权限。

建议顺序：

- 先做 VIP
- 再做单章购买

因为 VIP 的状态机更简单，更适合新手打第一套支付链路。

## 十八、建议你现在立刻做的一个小练习

为了确认你真的跑通了项目，而不是只是照抄代码，建议你自己做下面这个练习：

### 练习目标

在首页再新增一本书，并让它也能进入详情页和阅读页。

### 练习步骤

1. 在 `books` 集合再插入一条书籍数据
2. 在 `chapters` 集合插入这本书的两章内容
3. 回到首页刷新
4. 点击第二本书，验证数据链路是否正确

### 这个练习的意义

如果你能独立完成它，说明你已经真正理解了：

- 数据怎么建
- 页面怎么读数据
- 书和章节如何关联

这比继续复制更多代码更重要。

## 二十、一句话总结

如果你是微信生态新手，第一阶段最重要的不是做复杂功能，而是：

> **先把“小程序页面从云数据库读出小说内容”这件事完整跑通。**

只要你完成了这一步，后面的登录、付费、VIP 和后台就不再是“完全陌生的问题”，而是基于已有项目逐步往上加功能。
