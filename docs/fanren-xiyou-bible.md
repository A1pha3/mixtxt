# 《凡人西游记》创作手记（全书一致性基座）

> 用途：锁定全书既成事实、人物设定、世界观规则、伏笔与钩子，供逐章校验时对照，避免剧情冲突与人物崩坏。随逐章通读持续补充。标注了章节来源，二次修改时务必回查该章。

## 一、世界观三层规则

### 物理层
- 灵气一年比一年稀薄，修士难再白日飞升，仙箓久不向凡间开（ch-01）。
- 灵气稀薄/浊化后，毒物异变敢伤人、妖物近村（ch-01、ch-02）。
- 五行山下旧猿封印时时松动；西行旧劫将重演（ch-intro、ch-02）。
- 天庭与灵山为续香火，要寻新一班取经人（ch-intro）。

### 社会层
- 青牛村属云梦泽西侧，弱、贫、老，村人多姓周、赵，和睦（ch-01）。
- 灵台方寸山：传说中菩提出世、仙人讲道之地，当地仙门，收徒益苛（ch-01）。
- 仙凡之隔巨大；凡人把持不住灵物，是祸非福（ch-02）。
- 招徒规则：十四岁及以下、根骨尚可皆可应试；现在云梦泽周边选外门徒，录取约十分之一（ch-02）。

### 约束层
- 青玉小瓶：能逆转草木枯荣、折叠"时日"，催熟靠瓶腹渗出的"气"，耗尽则暗，需沐夜露月光回润；非无中生有，催太急养母/母体跟不上（ch-01、ch-02）。遗训"勿授非人"（ch-01）。
- 遗训原文（"乾坤崩于一旦、勿授非人"）刻于半片残旧布帛，与青玉小瓶、刻字玉片一同取自枯骨（ch-01）。**注意：取自古洞，非瓶底。**
- 玉片残字首句："灵气流散，天地将闭，凡躯欲求长生，当自微末始……"（ch-01）。

## 二、人物档案

### 陆尘（主角，S 级）
- 身份：青牛村采药少年，14 岁（ch-01）。父早亡（3 年前风寒），母周氏哭瞎左眼、身虚。左手虎口旧疤（7 岁被獾子挠，阴雨天发痒）。识几个字，从老孙头处学认字辨药。
- 心性：不信仙佛，务实，只信自己的两条腿和药篓；重诺、顾母、机警、谋定而后动；自己"挣"的东西才踏实。
- 体格：比同龄高半头，眉眼单薄，肤色黧黑，白牙齐整。
- 设定钩子：儿时胸口常年压着一口"闷"，累则梗痛，如湿灯芯；遇瓶后似被"揉开"（ch-01）。

### 周氏（主角之母）
- 青牛村西头陆家，姓周，村人唤周氏。3 年前夫死哭瞎左眼、身垮。病重时下炕难。经陆尘用药瓶调理渐愈（ch-01、ch-02）。

### 老孙头（村中土郎中/开蒙人）
- 青牛村唯一土郎中，教陆尘认字辨药；消息灵通，深知仙凡内情（ch-01、ch-02）。

### 独眼刘（ch-02 反派，散修）
- 落魄散修，灰袍、左眼蒙黑布、右眼浊黄、腰挂酒葫芦、脚边锈剑。以探灵铜铃寻到青牛村，欲夺瓶。被陆尘以赤角蚰引敌+地形智取，负伤遁走，撂狠话"三日"之约（ch-02）。**伏笔：未归场，待回收。**

### 阿丑（ch-02 配角）
- 邻镇铁匠之子，憨壮，同赴灵台方寸山应试，与陆尘茶棚相识。验出灵根三品土属，录入外门正徒（ch-03）。隔三差五探陆尘，带来取经人等内幕信息（ch-04）。

### 苍崖子（ch-03+，仙门执事）
- 灵台宗外门掌簿，灰袍，腰悬铜牌。替宗门掌选徒簿。察觉陆尘经脉被灵物养过、起疑，却因"增录凡籍"敕令破例录为杂役，丢"杂"字铁牌。

### 苗伯（ch-04+，杂役药师）
- 灵台宗最老杂役，管药圃二十余年，供丹房灵草。背驼、脸色蜡黄、指甲嵌泥。当年也是伪灵根，自学认得全圃药。教陆尘辨药，赠《本草残卷》。口头禅式拒绝称师："唤伯伯便罢"。

### 小石头（ch-04，杂役童）
- 青牛村外瘦童，无灵根，家里凑半年盘缠买杂役名额混饭。与陆尘邻铺。

## 三、已成事实时间线（按章）

- ch-01：陆尘为母采药于野葛坡，遇赤角蚰，退避至老樟树下，发现山腹古洞；从枯坐不化的无名骸骨处取得青玉小瓶 + 刻字玉片 + 残旧布帛；枯骨散作白屑。回村瞒下。
- ch-02：瓶能催熟灵果（山楂核→山楂果，一夜）；陆尘悄悄用以调养母亲；自身五感渐利；独眼刘来犯，被智取退走；陆尘决定独闯灵台方寸山应试，出门上路，途遇阿丑。
- ch-03：灵台方寸山应试，三千余人取三百。陆尘验出伪灵根（四五道杂纹、细若游丝）被拒，因根骨被瓶养得瓷实+"增录凡籍"敕令，苍崖子破例录入**杂役籍**（铁牌"杂"字）。入斜月三星洞东侧薪火居，分到药圃随苗伯。瓶钮斜月三星刻纹与崖壁"斜月三星"四字照面，暗生"此山在等它"之念。**独眼刘循清气尾随上山，隐于应试人群**。
- ch-04：杂役挑水、认药得苗伯青眼，赠《本草残卷》。月中发劣丹（掺三成凡药、灵效不足真丹三成），识破仙门克扣。借瓶清气压涤劣丹杂质，夜里摸黑救枯玉髓草。月圆夜破入**炼气一层**（瞒住同屋）。阿丑传来两则内幕：青牛村一带夜有妖风起；宗门暗挑**新一批取经人**（灵山下法旨续西行旧缘）。独眼刘以探灵铜铃锁定清气来源，在山门护山大阵外死守。章末梦境：峰顶金光中毛脸老猴（六耳/石猴意象）"认得他"。
- ch-05：炼气一层杂役越阶退敌：毋伤独创斗法——瓶气补灵力（恃有"一汪用不完的泉"）、醉鱼藤活根埋铺底、痒见愁干粉塞窗棂，逼退炼气二层独眼刘（其左腿旧伤致跛是破绽）。战斗动静惊动杂役院与外门掌簿苍崖子；陆尘以"药缘+苦熬"说辞遮掩瓶，被提为**药童**（仍归苗伯，月粮添半份）。麻脸管事畏上、未必靠得住；独眼刘"铃记着瓶"仍在山脚游弋，威胁常驻。
- ch-06：下月初三去山脚鬼市（山门外三里，每月初三/十七开）。从盲眼老妪旧物摊以玉髓草换得残玉简，**揭示核心世界观：青玉瓶是镇元大仙（地仙之祖）"时空道则"崩碎后落的残片**，可折叠时日、催熟草木，然"道则反噬，非大根基不能御"。旧事：五庄观人参果"三千年一花/果、闻一闻三百六十年、吃一个四万七千年"。撞见来山脚的老孙头：周氏已大愈（头晕断根、左眼可辨人影、能下地劳作）；青牛村妖风渐紧（村东王家丢猪、坡上现绿眼）；少饮"取经人从凡籍新录弟子中挑"，陆尘自料贴合此选法，初觉被拨入三界大棋。**注：遗训表层"乾坤崩于一旦"（ch-01）与深层"时空崩—镇元道则"（ch-06）为逐层递进揭示，非矛盾。**
- ch-07：以"药圃采办寒露草"为由下山回村一夜。黄皮子精（炼气三层，野物凭本能）夜扰青牛村，陆尘凭机关+瓶气青光克制，钉其于墙遁走。**设定：瓶气反噬/泄漏会渗入土石，成招妖引怪之"饵"；读者得知陆尘能以道则同源"回收散气"（拔瓶收青牛村余气——"在哪儿落脚，便在哪儿把泄气收回干净"，成其长期行为准则）。**收气瞬间一股凝实清气东泄，独眼刘据此将猎杀圈锁定"青牛村—山道"。章末复现毛脸老猴梦境。
- ch-08：归山走僻林，独眼刘备生牛皮裹腿+乌绳铁蒺藜破机关，半道截杀。炼气一层不敌二层（机关/伤腿/轻敌三优势尽失），逼至绝境孤注一掷以瓶强冲筑基，**道则反噬**（青光威压震开独眼刘）；凭瓷实根骨+死志险还生，但筑基未成、境界跌至一层初期边沿。**立核心主题："我得有我自己的大根基"——瓶气养的是借来的力，扛不住反噬；大根基须一步步踩实。**独眼刘见非人之力胆寒，改策略"等其自爆再收尸取瓶"，仍为长线威胁。
- ch-09：伤愈后掌根更稳，残玉简拼出新句："道则既崩，天地失其枢……灵气岁薄，仙箓久闭……有物食道则，名之曰**'蚀'**……残片聚则补天，散则倾天"。揭示：古洞枯骨即**守瓶人**（代代相传、至死勿授非人），陆尘接手"守"的因果。**玉片图谱真相：非逞凶之术，而是"斜月三星"养根基慢功（膻中为"斜月"、三窍为"三星"，引气润根、多一分便伤）**——改修行之法，不再贪快。夜中瓶忽热，斜月三星洞前石猴泛起青光、隐活，遥闻老猿长啼——**五行山下旧猿封印松动（卷主线正式点燃）**。
- ch-10：夜探斜月三星洞，石猴口吐人言——是**五行山下旧猿（齐天大圣）的神念**，被灵山镇入石中做第二道锁。旧猿点破：五行之威也是道则之一，道则崩故五行衰故封印松；识得瓶（闻人文人参果/袖里乾坤气息）；警之"蚀"无形食道则、且"想倾天之人"在搜千数残片；灵山暗选新取经人是"拿新取经人血去补崩碎的道则"。对话泄瓶气致石猴张光，惊动山下独眼刘铜铃近山门。**尾钩：无安稳之夜。**
- ch-11：苗伯讲古印证石猴镇旧猿神念；陈二旧案（凡籍弟子被当棋子上调、事败废修下山）——"小人物或做棋子或做灰"。灵山征召令："凡籍中根骨奇绝/身怀异物者一概征召，抗命废修为"，陆尘在列之险。晨起玉髓草被无形啃空、山灵气薄一线→**"蚀"在啃这山**。章末旧猿急传："他们来了。"
- ch-12：勘破瓶中乾坤——瓶内另有洞天（青石丈许、悬团月华），**瓶内时光流速慢于瓶外约 1:3~4（"瓶中乾坤藏岁月"）**；但每入瓶修行消耗瓶中道则气（用多了瓶空成死玉）——"散则倾天"的守恒伏笔。独眼刘正面强夺不得，改**借灵山征召之网举发陆尘"身怀异物"**（飞鸽传书苍崖子），欲令其被征作取经人押上西行路再半道截杀。蚀循瓶气近药圃（灵犬萎顿、灵泉水暗）。**章末 cliffhanger：苍崖子亲自押陆尘去掌簿房核查异物。**
- ch-13：掌簿房中，陆尘以"祖传药玉、亡父留母念想、孝道不可弃祖物"搪塞交查（口径统一：祖上传下来→亡父→娘→他，前文"祖上传下来"与"亡父留给我娘"两版说辞已合并），苍崖子无实证、以"待查之人"留观（不得离山/返乡）。**天庭金敕降临：道则崩、仙路封——仙箓永闭、凡籍三百为末班，敕灵山自凡籍征"根骨奇绝或身怀异物"者补道则之缺**。陆尘因"身怀异物"被苍崖子当场点入征召短名单，进退皆死。独眼刘得信，移向云梦泽古驿道（西行首站）待伏，改"不硬碰、候在笼门外"。蚀因道则动荡盛一分（灵泉暗灰、生气被叼）；五行山旧猿封印再松一线。**章末决断：入瓶中乾坤，"一日当作三四日"速养根基，把伪灵根养成真灵根、踩出大根基，"不必做灵山案上待宰的祭品"。**

## 五、文风基准（story-craft 对齐）
- 短长句交替，忌"仿佛/似乎/宛如"堆叠；感官锚点("湿灯芯""象被人揉开")；行动节拍代替"他说"；正文无说明书式全知心理归因；每章末尾留钩。
- 战斗写实：借地形、借器物、斗智多于斗力（独眼刘一战为范本）。
- 情绪经身体反应传达（"腿肚子直打颤"）。
